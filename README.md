# Plant Buddies - Vue Prototype

A simple prototype for the Plant Buddies website built with Vue.js and vanilla CSS.

## Features

- Clean, responsive design
- Navigation menu
- Hero section introducing the platform
- Feature cards for key sections (Maintenance Q&A, Growth Sharing, Skill Exchange)
- Plant care guide section with category examples
- Community section with sample posts

## How to View

1. Open the `index.html` file in any web browser

## Technologies Used

- Vue.js 3 (via CDN)
- HTML5
- CSS3

## Note

This is a prototype without backend functionality. No database or user authentication is implemented at this stage.
